# 🚗 Animated Dream Car Landing Page

A modern, responsive landing page built with **HTML5** and **CSS3**, featuring smooth CSS keyframe animations, interactive hover effects, and a clean UI design. 

This project was developed as part of frontend web development practice to enhance user interaction through CSS transitions and animations.

---

## ✨ Features

- **Animated Header & Layout:** Smooth entry animations (fade-in, slide-down, and scale-in effects) upon loading the page.
- **Interactive Navigation:** Clean navigation bar with animated underline transition effects on hover.
- **Dynamic Feature Cards:** Cards that elevate smoothly (`translateY(-10px)`) when hovered over.
- **Responsive Design:** Styled using Flexbox and modern CSS properties for clean alignment across devices.
- **Custom Color Palette:** Designed with a professional teal and neutral gray color scheme.

---

## 🛠️ Technologies Used

- **HTML5:** Semantic markup structure.
- **CSS3:** Flexbox layout, keyframe animations, transitions, and modern styling.
